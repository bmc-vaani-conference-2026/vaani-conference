## Replacing Placeholder Images

1. **Speaker photos** — Place actual photos (JPG/PNG/WEBP) using the exact filenames above.
   - Recommended size: **400×400 px** or **square** for best results
   - The website gracefully shows initials-based placeholders if images are missing

2. **College logo** — Replace `assets/logos/college-logo.png` with the actual logo.
   - Recommended size: **200×200 px** (transparent background preferred)

3. **Campus photo** — Replace `assets/college/college-campus.jpg` with an actual photo.
   - Recommended size: **800×600 px** or **4:3 aspect ratio**

## Features Implemented

- ✅ **15 complete sections** as per the master prompt
- ✅ **Animated particle/neural-network canvas** background (hero)
- ✅ **Live countdown timer** (IST-aware, auto-switches to Live/Ended messages)
- ✅ **Sticky navbar** with blur on scroll + mobile hamburger menu
- ✅ **Scroll-triggered reveal animations** (Intersection Observer)
- ✅ **Fully responsive** (1440px → 375px tested)
- ✅ **Keyboard-accessible** navigation
- ✅ **`prefers-reduced-motion`** support
- ✅ **Image error fallbacks** (SVG placeholders)
- ✅ **Semantic HTML5** structure
- ✅ **SEO meta tags** (Open Graph, description, keywords)
- ✅ All CTA links connected to real URLs
- ✅ Clickable phone (`tel:`) and email (`mailto:`) links
- ✅ No backend / no database required

## Deployment

The website is a **static HTML/CSS/JS** site. Simply upload the entire `Bmc/` folder to any web host:

- **GitHub Pages** — push the folder, enable Pages
- **Netlify** — drag-and-drop the folder
- **Firebase Hosting** — `firebase deploy`
- **Traditional hosting** — FTP upload the folder

No build step or server required.
